# แนวทางการทดสอบและแคปภาพหน้าจอส่งงาน (สิ่งที่ส่งข้อ 3)

ให้เปิดเบราว์เซอร์บนเครื่อง Client (ที่ตั้งค่า `hosts` ชี้ไปที่ `192.168.1.20` แล้ว) และแคปภาพหน้าจอ **ให้เห็นทั้งแถบ URL ด้านบนและเนื้อหาหน้าเว็บ** ครบทุกกรณีดังนี้:

1. **หน้าแรก (`http://www.id-239.com/`)**
   - แสดงหน้า Portal และลิงก์ไปยังบริการต่างๆ

2. **หน้า About (`http://www.id-239.com/about`)**
   - แสดง **รูปภาพ, ชื่อ `Yutthasatr Khumkhonsue` และรหัส `68130239`** ชัดเจน (`app-about`)

3. **หน้า Research (`http://www.id-239.com/research`)**
   - แสดงสรุปงานวิจัยวิชาสัมมนาความยาว 300 - 500 คำ (`app-research`)

4. **หน้า API (`http://www.id-239.com/api/Hello%20K8s%2068130239`)**
   - แสดงข้อความต่อท้าย URL เป็น **ตัวอักษรขนาดใหญ่ กลางจอ** (`app-api`)
   - *(แนะนำ: ลองทดสอบทั้งภาษาอังกฤษและภาษาไทย เช่น `/api/ทดสอบระบบ` เพื่อแสดงว่าทำงานได้จริง)*

5. **หน้า Admin แก้ไขงานวิจัย (`http://admin.id-239.com`)**
   - แคปหน้าจอที่ 1: หน้าฟอร์มแก้ไขข้อความใน `admin.id-239.com`
   - ทดลองแก้ไขข้อความสรุปงานวิจัย (300 - 500 คำ) แล้วกดปุ่ม **บันทึกข้อมูล (Save)**
   - แคปหน้าจอที่ 2: แถบแจ้งเตือนสีเขียว "บันทึกข้อมูลสรุปงานวิจัยเรียบร้อยแล้ว!"
   - แคปหน้าจอที่ 3: กลับไปเปิด `http://www.id-239.com/research` (กด Refresh) เพื่อยืนยันว่าข้อความถูกอัปเดตตามที่บันทึกจาก `admin.id-239.com` จริง!
